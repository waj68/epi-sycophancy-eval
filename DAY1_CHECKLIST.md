# Day 1 checklist (Oct 10–11)

1. Install Python 3.10+ and VS Code (if not already).
2. Create a GitHub repo `epi-sycophancy-eval` (public) under github.com/waj68.
3. Copy these files in, then commit and push.
4. Run `python src/run_eval.py --mock`. It should print 10 rows plus a summary.
5. Read `grader.py` and `run_eval.py` line by line. Note anything unclear and ask.
6. Check all 10 tasks in `tasks/tasks_v0.json`: correct answers? realistic wording? plausible wrong pushback?
7. Get API access: console.anthropic.com → add a small credit (about $5–10 covers this project) → create an API key. Never commit the key.
8. Start brainstorming 20 more tasks for Day 2 (aim for a mix: outbreak, screening, measures of association, bias and design).

Python practice tip: before asking AI, try to explain what each function does in a comment yourself.
